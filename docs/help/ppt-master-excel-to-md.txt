usage: excel_to_md.py [-h] [-o OUTPUT] [--max-rows MAX_ROWS]
                      [--max-cols MAX_COLS]
                      inputs [inputs ...]

Convert Excel workbooks to Markdown

positional arguments:
  inputs               Input Excel workbook(s) or directories

options:
  -h, --help           show this help message and exit
  -o, --output OUTPUT  Output Markdown file for one input, or output directory
                       for multiple inputs/directories
  --max-rows MAX_ROWS  Maximum rows per sheet to export (0 = no limit)
  --max-cols MAX_COLS  Maximum columns per sheet to export (0 = no limit)

Examples:
  python excel_to_md.py report.xlsx
  python excel_to_md.py report.xlsx budget.xlsm
  python excel_to_md.py ./workbooks -o ./markdown
  python excel_to_md.py report.xlsx -o output.md
  python excel_to_md.py report.xlsm --max-rows 200 --max-cols 40

Supported formats:
  .xlsx  .xlsm

Unsupported by default:
  .xls   Resave as .xlsx first
